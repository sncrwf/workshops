Você criou, em cerca de 45 a 60 minutos, uma aplicação no ServiceNow utilizando o novo **Creator Studio**.

Sua aplicação contém uma tabela para armazenar os dados das solicitações, um item de catálogo para que seus usuários possam enviar suas solicitações, uma automação para gerenciar aprovações e, potencialmente, outras etapas importantes do processo. Por fim, um workspace para que os usuários do processo tenham uma visão geral dos processos atribuídos a eles.

**Isso conclui o laboratório**
