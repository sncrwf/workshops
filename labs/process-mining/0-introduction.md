**Como usar Process Mining para identificar oportunidades de melhoria de processos**

Process Mining está revolucionando a forma como entendemos a eficiência operacional das organizações. A solução de Process Mining da ServiceNow automatiza a análise dos seus fluxos de trabalho, revelando onde há oportunidades para melhorias que gerem valor duradouro ao negócio.

Neste laboratório, você aprenderá tudo o que precisa para começar a utilizar o Process Mining ao retornar ao seu trabalho. Vamos abordar como usar o **Analyst Workbench** para interagir com dados de processo, identificar oportunidades de melhoria e criar seu primeiro projeto de Process Mining.

Hoje, abordaremos apenas a superfície do que é possível fazer. Se quiser se aprofundar mais no tema após o laboratório, salve este link: [Guia para começar com Process Mining](https://www.servicenow.com/community/process-mining-blog/guide-to-getting-started-with-servicenow-process-mining/ba-p/2905413).
